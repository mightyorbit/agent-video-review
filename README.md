# Agent Video Review

A local video player, timestamped feedback board, and command line loop for people and their editing agents. It runs on the editor's computer with Python's standard library. Review files stay in a directory you choose. FFmpeg is optional for the built-in trim renderer.

**Version:** 0.1.0. Licensed under MIT; see LICENSE.

## Quick start

Prerequisites: Python 3.10 or newer; a current browser that can play your MP4, WebM, or MOV file. FFmpeg is needed only for render. No cloud account or API key is needed.

From this directory:

    python3 review.py init reviews/demo --title "Demo cut"
    python3 review.py add reviews/demo /path/to/your-cut.mp4 --note "First cut"
    python3 review.py serve reviews/demo

Open the printed http://127.0.0.1:8765/ URL on the same computer. Pause on a moment, optionally select in and out, and enter feedback. Then in another terminal:

    python3 review.py comments reviews/demo
    python3 review.py comments reviews/demo --json
    python3 review.py status reviews/demo c-12345678 addressed --note "Shortened the pause"
    python3 review.py add reviews/demo /path/to/revised-cut.mp4 --note "Round 2"

Replace the example comment ID with one from your own review. The same project holds all versions. Feedback always refers to the version on which it was written. The browser switches versions and shows their comments.

## Install for an agent

Keep the full folder together: SKILL.md, README.md, review.py, player.html, and examples. The agent needs access to the review project directory and local Python. The browser review is for the human on the computer running the server.

Clone the repository first:

    git clone https://github.com/mightyorbit/agent-video-review.git
    cd agent-video-review

For Codex on macOS or Linux, copy the repository folder to ~/.codex/skills/agent-video-review/:

    mkdir -p ~/.codex/skills/agent-video-review
    cp -R SKILL.md README.md LICENSE VERSION review.py player.html examples tests ~/.codex/skills/agent-video-review/

For Claude Code on macOS or Linux, copy it to ~/.claude/skills/agent-video-review/:

    mkdir -p ~/.claude/skills/agent-video-review
    cp -R SKILL.md README.md LICENSE VERSION review.py player.html examples tests ~/.claude/skills/agent-video-review/

Restart or refresh the agent's skills. These paths follow conventional local skill layouts; the package has been smoke tested as a Python CLI and local HTTP app, not end-to-end in either agent host. On other systems, place the folder in the host's documented skill directory or point an agent directly to SKILL.md.

Run commands with the installed absolute path to review.py or from the package directory. Review projects may live anywhere writable. The CLI copies a cut into PROJECT/media/ and does not modify the source.

## Edit example

The optional renderer uses keep ranges in seconds. See examples/keep-ranges.json:

    {"keep": [[0, 1.5], [2.5, 4]]}

This keeps 0–1.5 seconds and 2.5–4 seconds of a source with both video and audio:

    python3 review.py render /path/to/source.mp4 examples/keep-ranges.json /path/to/new-cut.mp4

The renderer creates a new H.264/AAC MP4. It rejects an existing output path. It is intended for simple cuts; use a proper editing timeline for transitions, captions, color, or multi-track audio. Check boundary frames and audio after every render.

To create synthetic demo media with FFmpeg rather than using private footage:

    ffmpeg -f lavfi -i testsrc2=size=640x360:rate=30 -f lavfi -i sine=frequency=440 -t 4 -c:v libx264 -c:a aac synthetic.mp4

Expected feedback entry, with an ID generated by your own run:

    c-12345678 v1 1.25-1.75s: Tighten this pause

JSON entries additionally include created time, note, and status. Statuses are open, addressed, resolved, and wontfix.

## How it works

- review.py stores review.json and media/vN.ext in each project. Its CLI creates versions, prints comments, updates status, and performs simple EDL renders.
- The server binds to 127.0.0.1 only. player.html gets state through /api/state, posts comments to /api/comment and status changes to /api/status, and streams video from /media/ with byte-range support for seeking.
- No database, telemetry, remote calls, uploaded media, or third-party Python packages are used.
- review.json is the editable data record; back up the entire project directory if you need its history.

The implementation is independent of any private hosted review service. It has no cross-device sharing, accounts, drawing annotations, waveform, notifications, or automatic AI editing. Use a secure tunnel or a separate reviewed hosting deployment if remote review is needed; do not simply bind this unauthenticated server to a public interface.

## Troubleshooting

- Empty player: run add first and check that your browser supports the file codec. MP4 with H.264/AAC is the safest example.
- Cannot connect: leave serve running and open the exact printed localhost URL on that computer. Use --port 8766 if the port is occupied.
- Seeking fails: try a browser-friendly MP4 with faststart metadata; the server supports HTTP byte ranges.
- Render fails: install FFmpeg, provide source footage with both video and audio, and make sure each keep range is ordered, within the footage, and has end greater than start.
- Comments appear missing: select the version on which they were made. CLI --json shows comments across all versions.
- Permission denied: choose a writable project directory. Do not run as administrator to work around an unclear permission error.

## Privacy and security

Only add footage you are authorized to use. The server has no authentication because it is restricted to localhost. Anyone with local access to the project files can read media and feedback. The browser uses text insertion, not HTML interpretation, for comments. Requests are size-limited and media paths are constrained to version filenames. Avoid placing projects in synced or public folders unless intended. Review media and feedback can contain personal or confidential information. Back up or remove them according to your own retention policy.
